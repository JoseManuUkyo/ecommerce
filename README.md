Descripción general del proyecto

Sistema de gestión 
Lo que queremos hacer es hacer un sistema en donde se lleva un control del inventario de ingredientes
que se ocupan en una repostería, además de la venta de los productos que están disponibles en dicho lugar,
y que puede usar para llevar un control de las ventas, fecha de elaboración, fecha de caducidad, cuantos quedan 
disponibles y de eliminar los postres que ya esta n caducados o que ya no están 
disponibles. 

El proyecto será  un programa que, lo primero que se necesitara para comenzar es 
pedir un usuario y contraseña para poder ingresar a lo que va a ocupar, si se requiere 
para hacer una receta, se ocupara un boto n que diga “Repostería”. Cuando el usuario lo 
selecciona, se abre una ventana que muestre un buscador y que pueda escribir el 
nombre de la receta que necesite y que al momento que se seleccione la receta en un 
lado muestre el inventario de los ingredientes y en caso de que falte o no haya 
aparezca un mensaje que diga que “La receta no se puede hacer, faltan ingredientes”, 
en cambio, si hay todos los ingredientes eso los descontaran del inventario haciendo 
que disminuya.  
En cambio si es para vender, entonces se oprime un boto n que dice “Venta”, en donde 
se abre una ventana en donde se muestra que postres tienen y cuantos van a querer, 
esto va a depender de lo que se pide y si esta disponible, en caso contrario se le avisara 
que no hay ese producto y tendrá  que escoger otro.
