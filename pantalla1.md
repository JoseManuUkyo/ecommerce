Lo primero que se mostrara será un mensaje que diga bienvenido y después se le pedirá a la persona reconocerse para poder entrar.
En caso de que el empleado sea nuevo, debe de presentarse con un superior para poder darse de alta en el sistema, de lo contrario
no podrá usar la información que tiene.
En caso contrario el usuario debe estar registrado en una base de datos para verificar si esta adentro y eso hará que puedas iniciar con tu trabajo ya sea que estés en la caja o que necesites hacer una receta para hacer el producto.
